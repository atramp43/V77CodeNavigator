# Получение отчёта

1. На машине, где работает Конфигуратор, установите .NET 8 **Desktop Runtime x64**, если
   он отсутствует. SDK для запуска не нужен. Собранная версия framework-dependent.
2. Оставьте весь каталог проекта на D:. Если переносите на сервер, перенесите дерево
   с `src/V77CodeNavigator`, `logs` и `builds`, а не один EXE.
3. Запустите `builds/diagnostic-win-x64/V77CodeNavigator.exe` в том же интерактивном
   сеансе Windows, что и `1cv7.exe`. Штатно запускайте оба без повышения прав.
4. Откройте модуль в Конфигураторе 7.70.932. Закройте диалоги поиска/параметров.
5. В утилите оставьте флажок включения текста снятым и нажмите кнопку сбора.
6. За семь секунд переключитесь в окно 1С и щёлкните внутри текста модуля.
   Не переключайтесь в другие приложения до завершения снимка (максимум ещё 30 секунд).
7. Вернитесь в утилиту. Откройте папку отчётов кнопкой. Передайте `diagnostic-*.json`.
   TXT — только краткая сводка, полного JSON он не заменяет.

Для более полезной диагностики повторите сбор: без выделения в начале модуля,
без выделения ближе к концу, с выделенным словом, затем в другом открытом модуле.
Сообщите номер строки/столбца, который вы видите вручную, и наличие разделения окна.
Текст для первого анализа не требуется. Флажок включения содержимого добавляет в JSON
доступные тексты, значения и заголовки; включайте его только для подходящего тестового кода.

## Возможные результаты

- `Rejected`: в момент снимка активен не распознанный Конфигуратор. Повторите отсчёт
  и переключение. Приложение не посылает editor probes посторонним окнам.
- `Complete`: сбор завершён. Это ещё не подтверждение возможности F12.
- `Partial`: provider не ответил за 30 секунд; сохранён последний снимок.
- `UIAError` / `MSAAError` / Win32 error: интерфейс отсутствует, окно закрыто или
  доступ ограничен. Передайте отчёт для анализа. Не требуется автоматически повышать права.

Утилита не перемещает курсор, не копирует через clipboard, не отправляет клавиши,
не регистрирует F12 и не сохраняет конфигурацию. Не нужно нажимать F12 для диагностики.

## Доступ для самостоятельных интеграционных тестов

Укажите точный путь к 1cv7.exe и к отдельной тестовой копии базы, место запуска
Codex (этот компьютер или сервер), а также разрешённые действия. Для первого этапа
достаточно запуска Конфигуратора и чтения модулей. Изменение/сохранение тестового
модуля требует отдельного явного разрешения. Пароль не включайте в файлы проекта
или команды: при необходимости выполните вход вручную.

WinAPI-утилита должна работать непосредственно рядом с процессом 1С. Окно RDP на
локальном компьютере не предоставляет локальные HWND удалённых модулей. Рабочий
стол должен оставаться доступным для действий через интерфейс.

Проверенный прототип F12 для глобального модуля платформы 7.70.027 включается флажком «Включить F12» или аргументом --f12. Оставьте утилиту запущенной, поставьте курсор внутри имени и нажмите F12. Утилита кратко открывает штатные диалоги поиска и списка методов. Вне распознанного редактора F12 передаётся приложению. В области действия флажка он заменяет штатную команду «Отладчик». Снимите флажок для возврата этой команды.

## Настраиваемая навигация

Запустите приложение с --f12 или включите горячие клавиши флажком. Нажмите «Настроить горячие клавиши…», выберите поле команды, нажмите сочетание и сохраните. Backspace отключает команду. Поддерживаются F1–F24 с модификаторами и латинские буквы с Ctrl или Alt. Назначения хранятся в hotkeys.json в корне проекта.

| Сочетание | Действие |
|---|---|
| F12 | Ищет точное имя в списке методов текущего модуля, затем в глобальном. При отсутствии имени после второго поиска открытым остаётся глобальный модуль. |
| Shift+F12 | Ищет слово в модулях конфигурации и предлагает строки с явными Перем / Var и параметрами на строке заголовка. Выберите строку и нажмите Enter. Неявные переменные и продолжения многострочных объявлений пока не распознаются. |
| Ctrl+Shift+F7 | Открывает штатные результаты поиска целого слова в модулях. Двойной щелчок открывает соответствующую строку. |
| Ctrl+Shift+O | Список процедур и функций текущего модуля. |
| Ctrl+L | Штатный переход по номеру строки. |
| Alt+F2 / F2 | Установить или снять закладку / перейти к следующей. |

Включённые сочетания имеют приоритет в распознанном редакторе модулей. Закладки и номер строки реализованы через штатные команды 1С. Поиск вхождений и переменных выставляет параметры штатного поиска: модули, целые слова, без учёта регистра. Окно результатов содержит строки всей конфигурации. Переменные с одинаковыми именами из разных областей показываются для ручного выбора.

## История и фильтр методов

Alt+Left возвращает к исходной строке и столбцу после успешного F12 или выбора метода через F8. Alt+Right повторяет переход вперёд. F8 открывает методы текущего модуля с поиском по части имени. Введите часть имени, выберите совпадение и нажмите Enter. Escape закрывает выбор.

История хранится в памяти запущенного навигатора для открытых документов. Закрытие окна документа делает его сохранённые позиции недоступными. При изменении текста координаты не пересчитываются. Все три сочетания настраиваются в окне горячих клавиш.

## Окно, трей и перенос настроек

При изменении ширины окна кнопки переносятся на следующий ряд. «Окно → Скрыть в трей» оставляет навигатор запущенным. Если установлен флажок «При сворачивании скрывать окно в трей», так же действует кнопка сворачивания. Двойной щелчок по значку в области уведомлений возвращает окно. Через контекстное меню значка можно открыть окно или завершить работу.

При закрытии навигатор записывает размер окна, включение горячих клавиш, состав отчёта, поведение трея и назначения клавиш в navigator-settings.json в корне проекта. При запуске он загружает эти значения. Ключ --f12 принудительно включает горячие клавиши. Через «Настройки → Сохранить в файл…» можно сделать копию профиля, через «Загрузить из файла…» — применить её.
