# Проверки

## Автоматические

`dotnet run --project tests/V77Navigator.Tests -c Release` — автономный executable
test runner без внешних пакетов. При ошибке exit code 1, иначе 0. Это не проект
VSTest/xUnit: команда `dotnet test` не заменяет запуск runner.

Проверяются процедуры/функции, кириллица/латиница, регистр, комментарии, строки с
удвоенными кавычками и переносами, многострочные объявления, границы ключевых слов,
повторы и отсутствие определения, UTF-16 offsets, CR/LF/CRLF, 10 000/100 000 строк,
LIFO/ёмкость истории и политика допуска процесса/класса.

Тестовый WinForms host создаёт собственные **native** EDIT/RICHEDIT50W и password
контролы. Проверяются фактические WinAPI чтения текста, selection >65535, исключение
содержимого, отказ для неизвестных классов и сохранность текста/выделения. EM_SETSEL
используется только при настройке собственных тестовых контролов. UIA/MSAA проверяются
на собственном EDIT; ошибки provider сохраняются, успешная проверка приватности сама
по себе не означает наличие конкретного pattern.

Текущий результат: **17 passed, 0 failed**. Сборка Release и publish win-x64 завершены.
На текущей машине Windows 10 x64, SDK 10.0.401, target net8.0-windows. Обработка
100 000 строк около 0,1 с в этом тесте; это не скорость чтения реального модуля 1С.
Логи: `logs/tests.txt`, `logs/build.txt`; checksum: `logs/exe-sha256.txt`.

Собранный GUI запущен на интерактивном рабочем столе, текст инструкции и элементы
управления прочитаны через accessibility. Снимок окна через computer-use завершился
ошибкой `FrameArrived timed out`; нажатие кнопки через этот инструмент —
`coordinate input geometry is unavailable`. Полная визуальная проверка и полный
цикл GUI пока не подтверждены. CLI worker отдельно проверен из текущей ограниченной
оболочки: GetForegroundWindow вернул 0, получен отказ без editor probes, результат
`logs/smoke-rejection.json`. Для реального сбора нужно запускать GUI на интерактивном
рабочем столе, где работает Конфигуратор.

## Ограничения парсера

Это лексический индекс корректного исходника, не компилятор 1С. Он не валидирует тела
методов и параметры, не разрешает обращения через объект, не поддерживает экспорт
конфигурации и семантические контексты. Ключевое слово объявления ожидается первым
значимым токеном строки. Повторные имена возвращаются списком. Реальная кодировка
редактора и соответствие offsets должны быть проверены отдельно.

## Интеграция с 1С

Успешная интеграция с Конфигуратором 7.70.932 **не заявляется**. До реального отчёта
не подключены F12/Alt+Left/Ctrl+Shift+O, смена выделения или переход между модулями.
На Windows Server 2022 исполнение пока не проверялось.

После получения отчёта: подтвердить редактор и полноту текста, сопоставить позиции
с ручными координатами, проверить большие/ANSI модули, несколько экземпляров,
разделение окон, закрытие/пересоздание HWND, отказ вне Конфигуратора, зависший provider
и разные уровни прав. Затем отдельно проверить обратимое перемещение курсора на
разрешённой тестовой базе без изменения исходника.

В реальном глобальном модуле тестовой базы проверены два вызова горячей клавиши F12 без выделения. Для glPrintCurCol получен ответ об отсутствии объявления. Для glStrFromCode128 выбран точный элемент штатного списка и диалог перехода закрылся. В положительном испытании каретка перед нажатием стояла внутри имени на строке объявления. Перемещение из тела другого метода к этой реализации ранее подтверждено отдельно через тот же штатный диалог. История переходов пока не подключена.

В тестовой базе проверены Ctrl+Shift+F7 для glValueTypeStr (139 результатов), открытие из списка модуля формы справочника Номенклатура и F12 из этой формы в открытый глобальный модуль. После перехода статус содержал glvaluetypestr, фокус вернулся в редактор глобального модуля. Shift+F12 на glPrintCurRow открыл список объявлений, выбор Enter вернул в глобальный модуль. Конечный номер строки переменной отдельно не сверялся.

На тестовом Конфигураторе проверены F12 из модуля формы справочника, возврат Alt+Left к строке 819, столбцу 39, и Alt+Right в глобальный модуль на строку 27169, столбец 41. Проверка использовала координаты MSAA из строки состояния. Фильтр F8 для glStrConvert дал один результат и завершился подтверждением перехода.
